# B2.1 — إثبات إصلاح العزل الجغرافي

## السبب والتغيير

- كان `resoudrePorteeTerritoriale` يقيّد `DELEGUE_PROVINCIAL` فقط؛ أدوار `RESPONSABLE_STOCK` و`SUPERVISEUR_TERRAIN` و`AGENT_DISTRIBUTION` تمرّ بلا قيد مقاطعة. كما كان استعلاما الدوائر والأحياء يضيفان شرط المقاطعة للمندوب وحده، فيتسرب الصف والعدد للأدوار الميدانية.
- أصبح ملف الدور التشغيلي النشط مصدر `province_id` الفعلي في جلسة الدور الميداني. ترفض الدالة المشتركة النطاق الغائب أو المتعارض، وتضيف شرط النطاق إلى استعلامي الصفوف والعدد.
- لمسؤول المخزن، لا تكفي المقاطعة: يلزم مخزن ولائي فعّال ومُسند إلى الحساب، وأن تطابق `entrepots.localite_id` موقع القراءة. طُبق القيد نفسه على قراءة الموارد الجغرافية بالمعرف. لا يملك المخطط الحالي إسنادًا أدق على مستوى القسم للمشرف أو الموقع لعامل التوزيع؛ لذلك يستخدم هذان الدوران `province_id` المسند في ملفهما القائم.
- الإدارة المركزية بقيت وطنية، والمندوب الولائي بقي مقيدًا بمقاطعته. لم تُعدّل المصفوفة أو البيانات أو migrations.
